# config-shop

سلام و عرض ادب 🌐

این پروژه با هدف ارائه و توسعه سرویس‌های مرتبط با کاهش پینگ، بهبود کیفیت اتصال، وب‌گردی و سرویس‌های VPN و کانفیگ آغاز شده است.

شروع این فعالیت در تاریخ ۱ سپتامبر ۲۰۲۶ (۱۰ شهریور ۱۴۰۵) انجام شده و هدف اصلی، ایجاد مجموعه‌ای منظم، ساده و قابل اعتماد برای ارائه سرویس‌های مختلف و توسعه تدریجی امکانات آن است.

در حال حاضر سرویس‌های زیر در مجموعه فعال هستند:

• WireGuard
• DNS

همچنین سرویس‌های زیر در حال آماده‌سازی هستند و به‌زودی به لیست اضافه خواهند شد:

• AmneziaWG
• Amnezia VPN
• OpenVPN
• v2rayNG

تلاش می‌شود سرویس‌ها به‌صورت مرحله‌ای توسعه پیدا کنند و در کنار کاهش پینگ برای بازی‌های آنلاین، امکان استفاده مناسب برای وب‌گردی و اتصال پایدارتر نیز فراهم شود.

این پروژه در ابتدای مسیر قرار دارد و امکانات، سرویس‌ها و بخش‌های مختلف آن به مرور تکمیل و بهینه خواهند شد.

از همراهی و حمایت شما سپاسگزارم
