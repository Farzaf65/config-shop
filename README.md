# درباره فعالیت پروژه

فعالیت این پروژه در زمینه ارائه و توسعه سرویس‌های کاهش پینگ، بهبود مسیر اتصال و سرویس‌های VPN و کانفیگ است. 🌐

تمرکز اصلی روی ایجاد سرویس‌هایی برای کاربران بازی‌های آنلاین و همچنین استفاده روزمره از اینترنت و وب‌گردی است. هدف این است که کاربران بتوانند متناسب با نوع استفاده و شرایط اتصال خود، سرویس مناسب‌تری را انتخاب کنند.

در بخش گیمینگ، سرویس‌هایی مانند WireGuard و DNS برای استفاده در بازی‌های آنلاین ارائه می‌شوند و در ادامه سرویس‌های بیشتری نیز به مجموعه اضافه خواهند شد. 🎮

در حال حاضر، پینگ بازی با توجه به شرایط اتصال، کیفیت اینترنت کاربر و موقعیت سرور، حدوداً در بازه ۴۰ تا ۱۰۳ میلی‌ثانیه قرار دارد و در بخش گیمینگ رجیستر بسیار خوب ارائه می‌شود.

⚠️ توجه بسیار مهم: میزان پینگ و کیفیت اتصال به شرایط اینترنت، اپراتور، مسیر ارتباطی، موقعیت کاربر و شرایط سرور بستگی دارد و ممکن است برای همه کاربران یکسان نباشد.

سرویس‌های WireGuard و DNS قبل از ارائه به کاربران تست شده‌اند و تاکنون سفارش‌ها و استفاده‌های زیادی از این سرویس‌ها انجام شده است. همچنین عملکرد سرویس‌ها بارها پیگیری و بررسی شده و تا این لحظه گزارشی از مشکل جدی از سوی کاربران دریافت نشده است.

برای استفاده در وب‌گردی نیز سرویس‌های مربوطه در حال آماده‌سازی هستند و جزئیات و شرایط آن‌ها به‌زودی اعلام خواهد شد. 🌐
